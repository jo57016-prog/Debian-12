# Debian 12 – Linux Server Configuration

## Deskripsi
Repository ini berisi dokumentasi instalasi dan konfigurasi Debian 12 (Bookworm) sebagai sistem operasi Linux Server.

## Tujuan
- Mempelajari sistem operasi Linux.
- Memahami administrasi server.
- Mempraktikkan konfigurasi jaringan komputer.
- Mendokumentasikan hasil pembelajaran TKJ.

## Materi
1. Instalasi Debian 12
2. Konfigurasi IP Address
3. Konfigurasi SSH Server
4. Konfigurasi DNS Server
5. Konfigurasi Web Server

## Operating System
- Debian GNU/Linux 12 (Bookworm)
